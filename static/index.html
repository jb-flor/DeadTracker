DeadTracker

Get Complete Data

DeadTracker relies on deadlock-api.com's passive data collection, which has small gaps in match history and live-match detection (a tracked player can occasionally show as offline while actually in a match). Their official fix is a lightweight local tool that contributes match IDs from your own Steam cache — not a Steam friend request.
Install deadlock-api-ingest (Windows)

Run this in PowerShell:

irm https://raw.githubusercontent.com/deadlock-api/deadlock-api-ingest/master/install-windows.ps1 | iex

Privacy-focused: only match IDs (salts) are submitted — no personal information or credentials. Runs as a lightweight background service; no admin rights required.

macOS, Linux, Docker, and manual-upload options are documented at deadlock-api.com/ingest-cache.
